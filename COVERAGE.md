# Implementation coverage

This is a teaching map, not an implementation backlog. Each row may need several lessons. "Prepared" means material exists; understanding requires the user to explain or apply it. Source files, configuration, tests, and deployment evidence must be read together where relevant.

The [real test-flow reference](reference/test-request-flow.html), added October 7, connects admission, worker claims, HTTP dispatch, Ray actors, computation, storage, provider finish, deployment, and validation limits. It supports source navigation across these areas; detailed learning and exercise evidence remain pending.
